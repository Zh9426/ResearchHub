## 开发与同步约定

每个完成且经过适当验证的开发迭代都应提交并推送到 GitHub。提交必须写清改动详情和迭代说明；未完成的工作及未通过的验证必须如实记录。

提交格式与操作流程见 [CONTRIBUTING.md](CONTRIBUTING.md)，逐次迭代记录见 [CHANGELOG.md](CHANGELOG.md)，后续工作见 [开发路线](docs/ROADMAP.md)。

科研数据、凭据和运行时个人记录不应随代码自动提交。应用内 GitHub 进度同步属于后续功能，当前只准备代码仓库与开发历史同步。
