# Research Hub v0.2 实施计划

基线：RH-003，`3cf52e0b18c301a8180c01cfba58d96c33fd585a`。开发分支：`codex/researchhub-v0.2`。完整授权需求见 V0.2_REQUIREMENTS.txt。

## Sprint 0：基础与恢复

- 备份既有 PostgreSQL 和 MinIO，保留用户账号与科研事实；0001 不变，新增 0002。
- 在 models/schemas/service/main 中冻结项目模块快照，提供人工升级预览/确认；所有校验使用项目快照。
- 从 service 层限制令牌的科研确认、删除和管理操作，增加负向授权测试。
- 核心对象归档、回收站、恢复、保留期后人工永久删除；对象 GC 保持数据库与文件一致、可重试。
- 新增 CI，运行现有与新测试、新迁移的保留数据验证、真实 Docker 与持久化/备份恢复；检查 UI 后独立提交。

## Sprint 1：研究工作流

- Capability、快捷创建、分组渐进表单、克隆与引用、独立星标；索引、分页检索、标签。
- Activity 隐藏边界独立于不可删除 Audit；项目导出 ZIP/Markdown。
- 标准 Bundle 先校验/预览，人工确认后导入；防路径穿越、重复、超限与部分写入。
- 通过真实 QA 数据库和 UI 验证，再独立提交。

## Sprint 2：研究理解

- 谱系、证据正反向追踪及降级影响；参数与指标 provenance/history。
- 扩展 manifest schema；导航、表单、仪表组件、专属视图使用 Registry，移除领域判断硬编码。
- 复用现有白/灰/青色设计系统，优化手机快速笔记、实验记录和照片上传，不做移动端打包部署。
- 桌面和移动视口浏览器复查、修复，再独立提交。

## Sprint 3：互联

- 语义明确且分页的 MCP 读写工具；显式用户请求才允许 AI 星标。
- 提供项目内 Skill/插件连接包，尝试 Codex 真实连接；协议测试与实际宿主连接分别报告。
- 查阅 OpenAI 官方安全远程 MCP/OAuth 能力，不开放公网或迁移科研数据。
- GitHub 仅保存代码来源，项目仓库、Run 分支/提交/Issue/PR；保持 ResearchHub 私有。
- 最终全量检查和浏览器审查，报告 IMPLEMENTED/TESTED/NOT VERIFIED/NOT IMPLEMENTED。

## 验证约束

单元测试使用隔离 SQLite，不能替代 PostgreSQL/MinIO 验收。真实验收只写 DEMO/SYNTHETIC QA 空间。个人数据库迁移前备份、迁移后比较既有行，禁止重置账号。没有物理手机/平板或外部客户端真实操作时明确 NOT VERIFIED。每阶段保持电脑快捷入口可用，并遵守 RH 编号和中文四段提交正文。
