你现在需要直接开发一个可实际运行的个人科研工作系统：

Research Hub

当前目标不是继续只写架构文档，而是交付：

Research Hub v0.1

这是一个真正可运行、可在电脑和手机访问、拥有独立数据存储，并能够继续扩展 ChatGPT / Codex / MCP 自动化能力的个人科研工作平台。

==================================================
0. PRODUCT DEFINITION
==================================================

Research Hub 不是：

- HDSP 专用管理工具
- ICE 专用管理工具
- 普通 Todo App
- Notion 克隆
- 实验记录表
- AI 聊天网页

它是：

“面向个人科研工作的 Research Operating System”。

核心目标：

1. 一个 Hub 管理多个科研课题；
2. 不同课题共享科研基础能力；
3. 每个课题又可以拥有自己的工作流、参数、指标和页面；
4. 手机和电脑使用同一套数据；
5. 科研事实保存在 Research Hub，而不是 ChatGPT Memory 或 Codex 对话中；
6. 后续 ChatGPT / Codex 可以通过 MCP 安全访问；
7. 后续 Codex 可以自动运行实验并回写结果；
8. 即使以后完全不用 OpenAI，Research Hub 本身仍可独立运行。

目前至少需要支持：

- Generic Research
- HDSP
- ICE-Sonocuring

三种 Project Module。

==================================================
1. FIRST VERSION GOAL
==================================================

本轮只开发 Research Hub v0.1。

目标是：

“做出一个真正能开始用于科研工作的第一版系统。”

本轮结束时，我应该能够：

1. 启动整个系统；
2. 创建并登录个人账号；
3. 在电脑浏览器中使用；
4. 在手机浏览器中使用；
5. 安装为 PWA；
6. 创建项目；
7. 选择项目类型；
8. 使用 Generic / HDSP / ICE 不同工作空间；
9. 创建 Research Run；
10. 填写参数和指标；
11. 上传 Artifact；
12. 建立父子 Run；
13. 管理任务和 Milestone；
14. 添加 Note 与 Decision；
15. 添加 Research Question 与 Hypothesis；
16. 查看 Evidence；
17. 查看项目 Stage / Gate；
18. 查看 Audit Log；
19. 数据实际保存到 PostgreSQL / Object Storage；
20. 重启容器后数据仍存在。

这是 v0.1 的核心验收标准。
